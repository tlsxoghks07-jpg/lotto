# 🎰 행운의 로또 번호 생성기 (Lucky Lotto Number Generator)

Streamlit 기반으로 제작된 웹 애플리케이션으로, 실제 로또 공 색상과 입체적인 3D 효과를 적용하여 로또 번호를 무작위로 생성해 주는 프로그램입니다. 최대 5세트까지 기록을 유지하며, 직관적이고 깔끔한 UI를 제공합니다.

## ✨ 주요 기능

- **랜덤 번호 생성**: 1부터 45 사이의 중복 없는 6개 숫자를 무작위로 추출합니다.
- **최대 5세트 누적 기록**: 번호 생성 버튼을 누를 때마다 화면에 누적되며, 최대 5세트까지 관리됩니다. 5세트가 모두 채워지면 축하 풍선 애니메이션이 나타납니다.
- **실제 로또 공 색상 적용**: 
  - 1 ~ 10: 노란색 (`#fbc400`)
  - 11 ~ 20: 파란색 (`#69c8f2`)
  - 21 ~ 30: 빨간색 (`#ff7272`)
  - 31 ~ 40: 회색 (`#aaaaaa`)
  - 41 ~ 45: 초록색 (`#b0d840`)
- **3D 입체 그라데이션 디자인**: 공 모양에 시각적인 입체감을 주어 실제 로또 공처럼 보이도록 구현했습니다.
- **초기화 버튼**: 언제든 기록을 지우고 처음부터 다시 시작할 수 있습니다.

## ⚙️ 요구 사항 (Prerequisites)

- Python 3.8 이상

## 📦 설치 및 실행 방법 (Quick Start)

1. 프로젝트 폴더로 이동합니다.
2. 필요한 패키지를 설치합니다:
   ```bash
   pip install -r requirements.txt
   ```
3. Streamlit 앱을 실행합니다:
   ```bash
   streamlit run app.py
   ```
4. 브라우저가 자동으로 열리면 행운의 로또 번호를 생성해 보세요!
